# ves-verify

Interim verification for legacy Windows systems still deployed by manual file
copy. Confirms production matches the UAT-approved release and detects drift
afterward.

Documentation lives in [docs/](docs/):

- [docs/README.md](docs/README.md) — project overview, layout, runtime
  assumptions, exit codes, and the top-level workflow.
- [docs/SERVERS.md](docs/SERVERS.md) — authoritative server and processor path
  map.
- [docs/SCRIPT-TESTING-GUIDE.md](docs/SCRIPT-TESTING-GUIDE.md) — operator-facing
  testing procedure.
- [docs/AGENTS.md](docs/AGENTS.md) — agent working instructions.
