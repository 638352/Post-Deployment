# Documentation Index

Use this folder as the canonical run-guide index for verification and testing workflows.

## Guides

- [CHEAT-SHEET.md](CHEAT-SHEET.md) — one-page plain-English overview of the testing process and what each script does
- [RUNBOOK-NON-TECHNICAL.md](RUNBOOK-NON-TECHNICAL.md) — a step-by-step guide for everyday testers
- [RUNBOOK.md](RUNBOOK.md) — the detailed technical runbook
- [UAT-PILOT-CHECKLIST.md](UAT-PILOT-CHECKLIST.md) — first UAT OutboundDBQ pilot (ops checklist)
- [AUTOMATION-POSTURE.md](AUTOMATION-POSTURE.md) — what is automated vs still manual

## Which one should I use?

- Read **CHEAT-SHEET** first if you want to understand the process before running anything.
- Start with **RUNBOOK-NON-TECHNICAL** for plain-language execution steps.
- Use **RUNBOOK** for full technical detail, command variants, and operational guardrails.
- Use **UAT-PILOT-CHECKLIST** when preparing the first UAT egress pilot.

## Recommended starting point

If you are new to this process, read [CHEAT-SHEET.md](CHEAT-SHEET.md) for the big
picture, then follow [RUNBOOK-NON-TECHNICAL.md](RUNBOOK-NON-TECHNICAL.md) to run it.
